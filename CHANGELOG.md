# Changelog

All notable project changes are documented here.

## 0.1.0 - 2026-09-04

### Added

- Deterministic supply disruption and recovery simulation.
- Eight base imperative WebMCP tools.
- Dynamic commit capability after explicit human approval.
- Dynamic undo capability after commit.
- Shared operator and agent state with visible audit attribution.
- Responsive network, order, plan, comparison, approval, and audit views.
- Sixteen deterministic engine tests.
- Public live demonstration and MIT-licensed source.

### Safety

- Human-only plan approval.
- Separate approval and commit actions.
- Bounded schemas and actionable validation errors.
- Read-only and untrusted-content annotations.
- Commit lock and explicit undo path.
