# Code Of Conduct

## Our Standard

We are committed to a respectful, professional, and harassment-free project community. Contributors should discuss ideas and code on their technical merits, give actionable feedback, respect different experience levels, and protect private or sensitive information.

Unacceptable behavior includes harassment, threats, discriminatory language, sexualized content, deliberate disruption, publishing private information, or using project channels for unrelated promotion.

## Scope

This standard applies in repository issues, pull requests, discussions, review threads, and project-related public events or communications.

## Enforcement

Report conduct concerns privately to the repository maintainers. Maintainers may edit or remove content, close discussions, reject contributions, or temporarily or permanently restrict participation when necessary to protect the community.

Maintainers will handle reports as confidentially as practical and will avoid conflicts of interest when reviewing them.
